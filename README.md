# 🚀 C# Practice & Mini-Projects

A collection of C# console applications, mini-games, and core programming concepts implemented in `Program.cs`.

---

## 🎮 Included Mini-Projects & Games

### 1. 🧮 Console Calculator
- **Features:** Performs Addition, Subtraction, Multiplication, and Division.
- **Error Handling:** Protects against division by zero.
- **Interactive Loop:** Allows users to run multiple calculations in one session.

### 2. ✂️ Rock, Paper, Scissors Game
- **Features:** Play against the computer with randomized AI choices.
- **Rules Logic:** Handles wins, losses, and draws for all combinations.
- **Quit Option:** Type `Q` anytime to exit the game.

### 3. 🎲 Number Guessing Game
- **Features:** Generates a random number between 1 and 100.
- **Feedback:** Gives "Too high" or "Too low" hints with total guess counter.
- **Play Again:** Option to replay after winning.

---

## 📚 Core C# & OOP Concepts Covered

- **Variables & Data Conversions:** Type casting, `Convert.To*` methods.
- **Console I/O & Math:** `Math.Pow`, `Math.Sqrt`, `Math.Floor`, `Random` numbers.
- **String Manipulation:** Methods like `ToUpper`, `Substring`, `Replace`, and String Interpolation `$""`.
- **Control Flow:** `if-else`, `switch-case`, `for`, `foreach`, and nested loops (star pattern rendering).
- **Arrays & Collections:** 1D Arrays, Multidimensional Arrays, and dynamic `List<T>`.
- **Exception Handling:** `try-catch-finally` block implementations.
- **Object-Oriented Programming (OOP):**
  - Classes, Objects, Constructors, and Methods
  - Inheritance (`Car : Vehicle`)
  - Abstract Classes & Method Overriding (`virtual` / `override`)
  - Interfaces (`IPrey`, `IPredator`)
  - Generics (`<T>`)
- **Multithreading:** Using `System.Threading.Thread`, `Thread.Sleep`, and parallel execution (`CountDown` & `CountUp`).

---

## 💻 How to Run

1. Open `MyfirstProgram.sln` in **Visual Studio** or **VS Code**.
2. Build and run the project (`Ctrl + F5` or `dotnet run`).
3. Uncomment specific code blocks in `Program.cs` to test individual features or mini-games.
